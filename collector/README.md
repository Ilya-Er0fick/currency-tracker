# Сборщик данных

Отдельный процесс на Python: опрашивает внешние источники и пишет свечи
в `price_candles`. Схему базы создаёт сервер, сборщик только пишет в неё.

| Задание | Источник | Активы | Период | resolution |
|---|---|---|---|---|
| crypto | Bybit `/v5/market/kline`, вторая (закрытая) свеча | `assets.source = 'bybit'` | `resolution_seconds` (60 с) | 1 |
| fiat | `open.er-api.com`, при Open — ЦБ РФ для RUB | `assets.type = 'fiat'` | `resolution_seconds` (сутки), в 01:00 UTC | 1440 |

Цена всегда означает «сколько USDT стоит одна единица актива». Курсы фиатных
источников («рублей за доллар») переворачиваются: хранится `1 / курс`.
USDT на бирже не торгуется сам к себе, его минутная свеча пишется с ценой 1.

## Режим реального времени

Сборщик держит WebSocket-подписку Bybit (`tickers.<SYMBOL>USDT`) только на
активы, которые кто-то сейчас смотрит, берёт из сообщений `lastPrice` и `ts`,
склеивает поток до одного значения в секунду на актив и передаёт серверу:

```
NOTIFY ticks, '{"asset_id": 2, "symbol": "BTC", "price": "63000.12", "ts": 1792410673000}'
```

`ts` — в миллисекундах, как его читает сервер (`time.UnixMilli`). В базу эти
котировки не пишутся. Для USDT пары на бирже нет: пока его смотрят, сборщик
раз в секунду отправляет цену 1.

Список зрителей сборщик получает от сервера:

```
NOTIFY watched, '[2, 3]'      -- массив asset_id, пустой — зрителей нет
```

Сервер отправляет его при каждом изменении и не реже раза в 10 секунд.
Если подтверждения нет дольше 30 секунд, список считается пустым и
соединение с биржей закрывается. Подписка на каждый топик — отдельным
запросом: биржа отклоняет запрос целиком, если в нём есть неизвестный
символ (например, TON).

## Запуск

Из корня проекта, `.env` берётся оттуда же (переменные окружения важнее файла):

```
python3 -m venv .venv
.venv/bin/pip install -r collector/requirements-dev.txt
.venv/bin/python -m collector
.venv/bin/python -m pytest collector
.venv/bin/ruff check collector
```

Тесты не требуют базы и сети: источники и хранилище в них подменяются.

Настройки — в `.env.example`, раздел «Сборщик данных».

## Отказоустойчивость

- Повтор только при таймауте, разрыве соединения, 429 и 5xx: паузы 1 с, 2 с, 4 с,
  не дольше бюджета цикла (¾ периода, для фиата не более 2 минут).
- Предохранитель у каждого источника свой. Open — после нескольких неуспешных
  циклов подряд; Half-open — один пробный запрос без повторов.
- Цикл крипты неуспешен, только если биржа не отдала ни одной свечи: отказ по
  одному символу — ошибка справочника, а не недоступность источника.
- Неуспешный суточный цикл фиата повторяется через `COLLECTOR_FIAT_RETRY_INTERVAL`;
  когда предохранитель er-api переходит в Open, курс рубля берётся у ЦБ.
- По SIGINT/SIGTERM начатый цикл дорабатывает (новые повторы не начинаются),
  затем закрываются HTTP-сессия и пул соединений.
